Greetingごあいさつ

音楽は、その場にいる人の心を確かに動かします。

株式会社東京アーティスト協会は、演奏家自身が中心となって運営する会社です。企業の式典やパーティー、ホテル・商業施設での演奏から、コンサートの企画・制作まで、音楽がお客様のもとへ届くまでのすべての工程に、私たち自身が関わっています。

演奏する側の事情も、会場を運営される側のご苦労も、どちらも現場で経験してきました。だからこそ「その日、その場所で何が最善か」を、ご一緒に考えることができると思っています。

音楽が人と人を自然につなぎ、初めて聴く方にも身近に感じていただける時間をつくること。それが私たちの願いです。どうぞお気軽にご相談ください。

株式会社東京アーティスト協会　代表取締役　大町めぐみ

Profileプロフィール

代表取締役 大町めぐみ二胡奏者・ピアニスト・プロデューサー

3歳から母の手ほどきでピアノを始め、ミュージカルや少年少女合唱団など、さまざまな舞台を経験してきました。守屋純子氏が率いる小中高生のビッグバンドにはピアニストとして参加し、日野皓正氏とも共演しています。

日本大学芸術学部在学中にavex artist academyの奨学生に選ばれ、エンタテインメントビジネスを学びました。大学主催のピアノコンサートでは選抜奏者としてカザルスホールの舞台に立っています。

卒業後は、ピアノ演奏と並行してコンサート運営、イベント制作、ライブサポートなどに携わる中で二胡と出会いました。二胡を玉蘭氏、ウェイウェイ・ウー氏、劉鋒氏、桐子氏に師事し、演奏だけでなく、音楽を届ける場そのものをつくる活動を続けています。

2022年には「敦煌杯」全日本二胡コンクールで銅賞を受賞し、二胡フェスティバルを主催。2023年にも二胡フェスティバルを開催し、アルバム『名曲COVERS』、2024年には『演歌セレクション』を発表しました。

2024年9月から中国政府奨学金を得て上海音楽学院・民族音楽学科二胡専攻へ2年間留学し、陳春園氏のもとで研鑽を積みました。留学中の2025年には「敦煌杯」全日本二胡コンクール壮年の部で銀賞を受賞しています。

現在は二胡とピアノの演奏を軸に、公演制作やアーティストプロデュースにも取り組んでいます。音楽が人と人を自然につなぎ、初めて聴く方にも身近に感じていただける時間をつくることを大切にしています。

プロデューサー 宮﨑 隆（フルーティスト・芸術制作家・アレンジャー・エンジニア）

茨城県鉾田市で生まれ育ち、現在は東京を拠点に活動しています。

私の音楽の原点は、小学生の頃にあります。自分から学校の先生にお願いしてピアノを教えてもらい、合唱の伴奏もしました。中学生になると、まだパソコンが珍しかった時代にDTMに出会い、音楽を「演奏する」だけでなく「つくる」ことにも夢中になりました。

高校では吹奏楽部でフルートと指揮に取り組みました。ステージ係も担当し、演奏するだけでなく、コンサートを支え、つくる側の面白さも知りました。高校時代には、たくさんのプロ演奏家から教えていただく機会にも恵まれました。

編曲や譜面づくりも、早くから続けてきたことの一つです。日本でFinaleがまだ広く使われていなかった頃から米国版を使い、編曲や譜面作成に取り組んできました。大学の卒業論文では、オペラを研究しました。

卒業後もさまざまな音楽家から学び、フルートを故・立花千春氏に師事したほか、ジェームズ・ゴールウェイ氏のマスタークラスも受講しました。クラシックを土台としながら、ジャズやワールドミュージック、世界各地の民族楽器にも関心を広げ、ジャンルを越えて音楽を学んできました。

若い頃から数多くの演奏の仕事に恵まれ、現場でしか得られないことを一つずつ身につけてきました。演奏すること、譜面を書くこと、音を録ること、舞台をつくること。振り返ると、どれか一つを選んだというより、音楽に関わることを夢中で続けてきた結果、そのすべてが今につながっています。

現在は、演奏家のキャスティングから、企画・舞台演出、舞台監督、音響、レコーディング、音源制作、編曲・譜面作成まで、音楽がお客様に届くまでのさまざまな工程に携わっています。

一つひとつの作業を自分で行えるだけでなく、舞台監督として全体を見渡し、必要な判断や指示をしながら、演奏家やスタッフと力を合わせて現場を一つにまとめることが得意です。

これまでに4,000件を超える音楽制作に携わり、1,000名を超えるプロミュージシャンの皆様とご一緒してきました。長年つくり続けてきた編曲・譜面データも、気がつけば約8,000曲になりました。

大切にしている言葉は「自他共楽」です。お客様も、演奏家も、制作する側も、みんなが心から楽しめることが、よい音楽につながると考えています。だからこそ、一つひとつの工程を大事に、丁寧につくることを心掛けています。

「こんなこと、できるだろうか」と思ったときは、どうぞ気軽に声をかけてください。まだ形になっていないアイデアでも大丈夫です。一緒に考えながら、その場にふさわしい音楽芸術をつくりましょう。
