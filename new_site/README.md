# MUSICIAN 実績欄更新（公開前ステージング）

## 方針

- 既存のロゴ、ヘッダー、フッター、ナビゲーション、配色、書体を維持します。
- 既存CMSの2018年以前の実績は削除せず、その上に2019〜2026年の「主な実績」を追加します。
- 新しい実績はテンプレート内の静的HTMLとして組み込むため、データベースは不要です。
- 年ごとの折りたたみ表示にして、実績数が増えてもページが過度に長くならない構成にしています。
- 2020年は恒久的な事業転換とはせず、ライブ開催が難しかった期間だけ配信・映像制作を活用し、その後段階的に通常公演へ戻った経過を記載しています。

## 公開候補データ

- 対象期間: 2019年〜2026年7月
- 掲載候補: 85件
- 主な根拠: 2018年6月以降の売上実績、株式会社MUSICIANと株式会社東京アーティスト協会の請求書、Outlookの案件メール、NASの写真・動画資料
- 請求金額、住所、口座、請求書番号、メールアドレス、非公開のやり取りは掲載データに含めていません。

公開候補の原稿は `data/achievements_recent.json` で管理します。

## 配置用ファイル

公開時にサーバーへ反映するファイルは次の2点です。

1. `deployment/app/View/catalog/cl01_3/default/index.html`
2. `deployment/app/webroot/css/recent_achievements.css`

1つ目は既存会社案内テンプレートの更新版、2つ目は実績欄専用の追加スタイルです。元のバックアップは変更していません。

## ローカルプレビュー

`preview/company.html` が現行ページへ実績欄を組み込んだ確認用ページです。

作業フォルダで次を実行すると確認できます。

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory "A:\AI\Web\MUSICIAN\new_site\preview"
```

ブラウザで `http://127.0.0.1:8765/company.html#achievements` を開きます。

## 再生成

公開候補データを更新した後は、次のスクリプトで配置用ファイルとプレビューを再生成できます。

```powershell
python "A:\AI\Web\MUSICIAN\tools\run_achievements_build_v2.py"
```
